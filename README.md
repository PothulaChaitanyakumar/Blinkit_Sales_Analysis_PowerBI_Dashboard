# Blinkit Sales Analysis | Power BI Dashboard

##  Project Overview

This project focuses on analyzing Blinkit sales data using **Power BI**. The dashboard was created to understand overall sales performance, product-level performance, outlet performance, and customer preferences.

The main goal of this project is to turn raw sales data into meaningful insights that can help understand business performance and identify areas for improvement.

##  Objectives

- Analyze overall sales performance
- Understand sales by product category
- Compare different outlet types and outlet locations
- Analyze customer preferences based on product attributes
- Identify high-performing and low-performing product categories
- Track important business KPIs
- Create an interactive and easy-to-understand Power BI dashboard

##  Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Cleaning & Transformation**
- **Data Visualization**
- **Data Analysis**

##  Dataset

The dataset contains information related to Blinkit sales and outlet operations.

Some of the important fields include:

- Item Type
- Item Fat Content
- Item Weight
- Item Visibility
- Item MRP
- Outlet Type
- Outlet Size
- Outlet Location Type
- Outlet Establishment Year
- Item Outlet Sales
- Rating

## 🧹 Data Cleaning & Preparation

Before creating the dashboard, the data was cleaned and transformed using **Power Query**.

The main steps included:

- Checking for missing values
- Handling inconsistent values
- Cleaning categorical columns
- Transforming data types
- Creating required calculated columns
- Standardizing values for analysis
- Preparing the dataset for visualization

##  Key KPIs

The dashboard includes important KPIs such as:

- **Total Sales**
- **Average Sales**
- **Number of Items**
- **Average Item Rating**

These KPIs provide a quick overview of the overall business performance.

##  Dashboard Analysis

The dashboard provides analysis of:

### Sales by Fat Content
Analyzed sales based on different item fat-content categories to understand customer preferences.

### Sales by Item Type
Compared sales across different product categories and identified categories contributing more to overall sales.

### Sales by Outlet Type
Analyzed the performance of different outlet types and compared their contribution to total sales.

### Sales by Outlet Location
Compared sales performance across different outlet location tiers.

### Outlet Establishment Trend
Analyzed sales performance based on the year in which outlets were established.

### Outlet Size Analysis
Compared sales across different outlet sizes to understand their contribution to overall performance.

##  Key Insights

Some of the major insights identified from the analysis include:

- Certain product categories contribute significantly more to total sales than others.
- Outlet type has a noticeable impact on overall sales performance.
- Different outlet locations show different sales patterns.
- Customer preferences vary based on product characteristics.
- The dashboard makes it easier to compare outlet and product performance.
- KPI cards provide a quick summary of the overall business performance.

##  Dashboard

The Power BI dashboard provides an interactive view of the analysis, allowing users to filter and explore the data based on different product and outlet attributes.
